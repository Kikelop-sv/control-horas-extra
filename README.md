# Control de Horas Extra v7

Versión PWA para GitHub Pages.

## Incluye

- Porcentajes bloqueados para evitar errores
- Color personalizado guardado en el navegador
- Modo oscuro/claro
- Exportar CSV
- Respaldar/importar JSON
- Registro de actividad por fila

## Porcentajes

- Normal: diurna 200%, nocturna 225%
- Descanso sábado/domingo: diurna 150%, nocturna 175%
- Asueto de ley: diurna 200%, nocturna 225%
